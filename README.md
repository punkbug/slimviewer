# SlimViewer

Lightweight and fast document viewer app for Android.

## Project Structure

- `app`: Main application module.
- `core`: Shared domain models and interfaces.
- `engine-office`: LibreOffice-based engine (Placeholder).
- `engine-hwp`: hwplib-based engine (Placeholder).
- `feature-home`: Home screen UI.
- `feature-viewer`: Universal viewer UI.

## Built With

- Kotlin
- Jetpack Compose
- Gradle Kotlin DSL

## How to Build

1. Open in Android Studio.
2. Sync Gradle.
3. Run the `app` module.

## Status

**Phase 1: Foundation & Scaffolding** is complete.
The project has a solid skeleton, file routing logic, and a placeholder UI.
Native engine integration (LibreOffice and hwplib) is pending in future phases.
