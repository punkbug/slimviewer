# SlimViewer rules

- This project is a real Android native app, not a prototype toy.
- Priorities: small app size, fast startup, simple UX, then format coverage.
- Never add unnecessary features.
- Never claim LibreOffice integration is complete unless it is actually wired.
- Use TODO comments for uncertain native engine integration.
- Prefer clean Kotlin and Jetpack Compose.
- Keep modules and dependencies minimal.
- Always propose a plan before major refactors.
- After every phase, summarize changed files and next risks.
